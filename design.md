# Doorstroom — besluiten

Eén regel per besluit; de onderbouwing staat in `docs/besluiten/`.

- [platform](docs/besluiten/platform.md) — web-PWA, vanilla JS, alles zelf op canvas, geen libraries (2026-10-25, user)
- [open-data](docs/besluiten/open-data.md) — OSM (OSM-API via serve.mjs, anders Overpass) voor wegen (Google mag niet), PDOK voor kaart, luchtfoto en zoeken; NDW later
- [simulatie](docs/besluiten/simulatie.md) — IDM per rijstrook, voorrang via kruisende koorden, verkeersafhankelijke VRI's, routes op gemeten tijden
- [meten](docs/besluiten/meten.md) — vóór/na in verse sims, gemeenschappelijk toeval per herkomst, 3 seeds, ruisdrempels
- [kosten](docs/besluiten/kosten.md) — spelwaarden; voorbereiding parallel, bouw opgeteld
- [hoofdthread](docs/besluiten/hoofdthread.md) — live simulatie op de hoofdthread, metingen in een worker (telefoon liep vast)
